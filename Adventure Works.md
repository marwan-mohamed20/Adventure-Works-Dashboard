# AdventureWorks Business Analysis Dashboard

An interactive **Power BI dashboard** that analyzes AdventureWorks business performance across sales, customers, products, and returns. The report has a clean dark theme and a Home Page that links to each analysis page.

## 📊 Dashboard Pages

- **Overview Analysis:** a summary of the key KPIs (Total Sales, Orders, Cost, Profit, Returns) with a sales running total, sales by category, and sales by region.
- **Sales Analysis:** sales trends over time, sales vs. target, sales by category and model, and sales, cost and profit by month.
- **Customers Analysis:** customer demographics (occupation, income, education, gender, marital status, age), top 10 customers, and average sales per customer.
- **Products & Country Analysis:** sales by country, region, subcategory and model, including a map view.
- **Returns Analysis:** total returns, return rate, returns by country, region and category, and a monthly returns comparison.

## ✨ Features

- Interactive slicers (Year/Month, Category, Subcategory, Region/Country)
- "Clear slicers" button on every page
- Easy navigation between pages
- Consistent, modern design

## 🛠️ Tools

- Power BI
- DAX
- Data Modeling

## 🚀 How to Use

1. Open the `.pbix` file in **Power BI Desktop**.
2. Start from the **Home Page** and choose an analysis page.
3. Use the slicers to filter the data, and click **Clear slicers** to reset.
